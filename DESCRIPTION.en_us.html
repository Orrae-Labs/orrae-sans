Orrae Sans is a wide, caps-only display typeface built from a modular geometric system. Lowercase text deliberately resolves to the same forms as uppercase text, giving headings, labels, and technical markings a consistent silhouette.

The family includes a Regular style with the Google Fonts Latin Core character set, numerals, punctuation, symbols, combining marks, and an alternate narrow A in Stylistic Set 1. The editable UFO source and deterministic build tools are maintained by Orrae Labs.
